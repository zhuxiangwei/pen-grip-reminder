# 握笔姿势提醒 · 运行依赖
#
# ⚠️ 三个必须知道的点
#
# ── 1. 必须用**系统 Python**（带 tkinter 的那个）
#    便携版 Python 不含 tkinter。本项目界面还没做（阶段 3 才做），
#    但环境固定用系统 Python，避免以后踩：
#      C:\Users\tmpee\AppData\Local\Programs\Python\Python312\python.exe
#
# ── 2. mediapipe 必须 `--no-deps` 安装，并**跳过 opencv-contrib-python**
#    它声明依赖 opencv-contrib-python，与 opencv-python 同时提供 cv2，
#    pip 替换时会删除几千个文件 —— 在受限环境下会撞上批量删除护栏而中断。
#    opencv-python 已经够用（已实测）。pip 事后报的
#    "mediapipe requires opencv-contrib-python" 提示可忽略。
#
# ── 3. 国内直连 PyPI 会很慢甚至卡死，务必带 -i 走镜像
#
# 安装步骤（照抄）：
#   python -m venv envs\pg
#   envs\pg\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple opencv-python
#   envs\pg\Scripts\python.exe -m pip install --no-deps -i https://pypi.tuna.tsinghua.edu.cn/simple mediapipe
#   envs\pg\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple absl-py certifi flatbuffers numpy
#
# 也可以直接复用坐姿项目的 venv（依赖完全覆盖）：
#   ..\posture-reminder\envs\posture\Scripts\python.exe
#
# ── 实测版本（本机 Windows 10 / Python 3.12.10）
